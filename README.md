# Pixel UI

Uma interface web em estética pixel art / 8-bit, construída com HTML, CSS e JavaScript puro.

## Executar
Abra `index.html` no navegador. Não é necessário instalar dependências ou executar um build.

## Estrutura
- `index.html`: estrutura da aplicação.
- `src/styles.css`: tema, componentes e layout responsivo.
- `src/app.js`: interações da interface.
- `assets/pixel-mark.svg`: marca vetorial em estilo pixel.

## Personalização
As cores principais ficam nas variáveis CSS no início de `src/styles.css`. Os cartões e atividades de exemplo podem ser alterados em `src/app.js`.

## Tecnologias
HTML5, CSS3 e JavaScript ES Modules. Sem frameworks ou dependências externas.
